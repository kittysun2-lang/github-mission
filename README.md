# 개인미션 — 플로깅 안내 페이지

## 실행

압축을 풀고 index.html을 브라우저에서 엽니다. HTML·CSS·media 폴더를 같은 위치에 유지합니다.

## 네 가지 문제

| 문제 | 해결 목표 |
|---|---|
| 1 | 제공된 대표 이미지가 표시됩니다. |
| 2 | 1280px에서 프로그램 카드 3개가 한 줄로 배치됩니다. |
| 3 | 신청 안내 버튼이 ‘참여 방법’ 영역으로 이동합니다. |
| 4 | 390px에서 가로 스크롤 없이 주요 내용이 모두 보입니다. |

## GitHub 기록과 제출

1. github-mission 저장소를 만들고 시작 파일을 먼저 올립니다.
2. 문제별 이슈 4개를 작성합니다.
3. 문제를 하나씩 해결하고 의미 있는 커밋 메시지를 남깁니다.
4. 이슈에 원인·수정 내용·확인 결과·관련 커밋 주소를 기록합니다.
5. 짝에게 한 문제 이상을 확인받고, 상대방의 이슈 댓글에 답합니다.
6. 제출양식.md를 작성하고 최종 코드와 함께 저장소에 올립니다.
7. 저장소 주소를 강사가 안내한 곳에 제출합니다.

실제 제출 마감은 강사의 안내에 따릅니다. 제공된 주제와 내용을 유지하고 오류 해결에 필요한 범위만 수정합니다. AI 사용은 가능하지만 원인·수정·확인 방법을 설명할 수 있어야 합니다.
